List and briefly explain the phases of the Software Development Life Cycle.

1. **Plannig** - This is where teams define what the software should do
2. **Requirements gathering and analysis** - this is where developers work with users of a software to understand the fuctionalities of the software
3. **Design** - This is where the blueprint of the sytem is created
4. **Implementation** - where coding is done based on requirements and design
5. **Testing** - where the software is tested for bugs, errors and security issues to ensure everything works pefectly
6. **Deployment** - where the finished or beta version of the software is released to the users
7. **Maintenance** - where periodical updates are dine to the software to fix bugs, improve performance

Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance.
1. **Unit testing** - involves testing individual componnents or functions of the software in isolation
    Importance
    - Detects errors in development
    - Ensures each piece of code works correctly before integration
    - Helps maintain code quality
2. **Intergration testing** - it checks if different modules or componnets of a system work together correctly
    Importance
    - It identifies issues in data flow and communication bettween modules
3. **System testing** - it evaluates the entire software application to check if it meets functional and non-functional requirements
    Importance
    - It validates entire application functionalities
4. **Acceptance testing** - It ensures the software meets bussiness needs and is ready for deployment
    Importance
    - It confirms that software is user friendly and meets customer needs

Define prompt engineering and discuss its importance in interacting with AI models.
**Prompt Engineering**  is the process of designing and refining input prompts to guide AI models, such as ChatGPT, to generate accurate, relevant, and useful responses.
Importance
1. Well-structured prompts help AI models produce precise and relevant answers.
2. The way a question is phrased can lead to more creative and structured responses.
3. Clear prompts minimize ambiguous responses and reduce unintended biases in AI-generated content.
4. Well-designed prompts reduce back-and-forth clarifications and get the right answer faster.
